# BIOL60791 Bioinformatics
## University of Manchester MSc Bioinformatics and Systems Biology
### Project description:

This project aims to use publicly available RNAseq datasets to visualise and quantify the expression levels of microRNAs in two embroynic stages of *Drosophila melanogaster*, using the deep sequencing tools available with Galaxy. You will prepare RNAseq data for analysis, map reads to the genome, count reads derived from microRNAs, and assess differential expression.

### Task:
1. Load RNAseq into Galaxy
2. Map sequence reads to the genome, using Bowtie2
3. Visualise the read mappings using IGV
4. MicroRNA differential expression, using DESeq2
5. Produce a report of the findings
