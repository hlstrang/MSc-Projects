# BIOL60201 Programming Skills
## University of Manchester MSc Bioinformatics and Systems Biology
### Project Description:

This project is designed to be completed by a group of 4 people and is divided into a series of tasks. You are given a genome sequence from a bacterial organism, which has just been sequenced. An experimental group working on this organism wishes to carry out some proteomics experiments to identify proteins from the microbe. However, they need a set of proteins in a FASTA formatted file which they will search with their mass spectra in order to identify which proteins were present in their experiment. They then want to know which is the best digestive enzyme to use, so that they get the best chance of identifying as many proteins as possible. The problem has been divided into
4 main tasks:

1. Predicted protein ORFs from genome nucleotides
2. Digested peptides
3. Convert sequence to mass
4. Peptide mass data & stats

I completed Task 1 of this project -- An ORF finder. This script needed to read in a FASTA file containing nucleotide sequences and find all possible ORFs, assuming the longest ORF will be used. ORFs must be predicted from all six reading frames.
